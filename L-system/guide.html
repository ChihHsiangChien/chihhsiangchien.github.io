1. 什麼是 L-System？

L-System（Lindenmayer System）是由生物學家 Aristid Lindenmayer 於 1968 年提出的字串重寫系統，最初用來模擬植物細胞分裂、枝條分岔與葉序生長，同時也是繪製幾何碎形（如科赫雪花、謝爾賓斯基三角形）的強大工具。

  • Axiom（初始公理）：第 0 代的起始字串，例如 F 或 F-F-F-F。
  • Rules（替換規則）：每一次迭代時，將字串中的每個符號同步替換成指定字串。
  • Angle（旋轉角度）：遇到 + 或 - 時海龜繪圖轉動的角度。

2. 繪圖符號對照表

F / G / Fl / Fr 向前移動一步並畫出線段
f 向前移動一步但不畫線（跳躍）
+ / - 順時針（+）或逆時針（-）旋轉指定角度
| 原地迴轉 180°
[ 與 ] [ 儲存目前位置與方向（開始分枝）；] 回到儲存點（結束分枝）
X 結構輔助符號（於本實驗室中會繪製節點小圓）

3. 迭代展開實例：植物分枝

設定 Axiom = F、Angle = 25.7°、規則 F -> F[+F]F[-F]F：

第 0 代 F
第 1 代 F[+F]F[-F]F
第 2 代 F[+F]F[-F]F[+F[+F]F[-F]F]F[+F]F[-F]F[-F[+F]F[-F]F]F[+F]F[-F]F

每一次按「▶ 迭代生長」，每個 F 都會長出自己的左右側枝，形成自相似（Self-similar）的植物碎形結構。

4. 進階語法：機率規則與前後文規則

  • 隨機機率規則：在規則前方加上機率權重，例如：
    F -> (0.5) F[+F]F 與 F -> (0.5) F[-F]F，每次生長都會產生獨一無二的樹形！
  • 前後文相依規則：使用 左鄰 < 目標 > 右鄰 -> 結果，可模擬植物荷爾蒙訊號沿枝幹傳遞的行為。

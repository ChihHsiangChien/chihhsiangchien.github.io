小腸絨毛構造與養分吸收動態模擬

觀察大分子養分如何由左方進入腸腔，經腸液與刷狀緣酵素分解為小分子，並分別由微血管網與乳糜管吸收運送

微血管吸收 (水溶性) 0
乳糜管吸收 (脂溶性) 0

1. 投放養分分子 (由左方進入)

點擊按鈕立即從左側腸腔釋放特定大分子養分，或開啟自動連續進食：

2. 消化與吸收歷程

1
左方流入與酵素分解

大分子養分從左方進入小腸腔，靠近絨毛上皮細胞（刷狀緣）時，被小腸液酵素／刷狀緣酵素催化分解為小分子。

2
穿過絨毛上皮細胞吸收

分解後的小分子（葡萄糖、胺基酸、脂肪酸與甘油）穿過單層絨毛上皮細胞進入絨毛內部。

3
分流運輸並隨血液/淋巴流動

水溶性 葡萄糖、胺基酸進入微血管 ➔ 匯入小靜脈隨血液流走。
脂溶性 脂肪酸與甘油重組為乳糜微粒進入中央乳糜管 ➔ 隨淋巴液流走。

3. 構造說明 (點擊畫布標示可高亮)

👆 點擊畫布上的構造名稱或養分粒子

小腸內壁有許多環狀皺褶，上面布滿指狀突起的「絨毛」，絨毛表面還有微絨毛，能大幅增加吸收表面積。每根絨毛內部都有豐富的微血管網與中央的乳糜管。

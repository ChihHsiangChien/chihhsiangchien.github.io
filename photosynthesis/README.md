# 光合作用互動實驗室 (Photosynthesis Interactive Lab)

一個高視覺質感、互動式的植物生理與光合作用生化機制教學模擬系統。

## 核心互動特色與功能

1. **光合作用生成葡萄糖、韌皮部 24 小時持續運輸與暫時性澱粉蓄洪**
   - **大氣 CO₂ 擴散與水分子木質部上行**：CO₂ 經氣孔擴散進入葉片，根部吸收水分子沿木質部導管因蒸散拉力上升至葉綠體。
   - **卡爾文循環生成醣類與日間即時蔗糖運輸**：光反應水解水釋放 O₂，基質碳反應固定 CO₂ 生成醣類。大量固定的碳在細胞質即時轉化為【蔗糖】，並透過韌皮部裝載（Phloem loading）立即輸送到庫器官（日間即時供應）。
   - **暫時性澱粉蓄洪機制**：日間光合速率往往大於韌皮部的即時外運負荷，多餘的碳聚合成不溶性暫時性澱粉粒「蓄洪」暫存，**防止細胞質游離單醣引發高滲透壓損害葉細胞**。
   - **夜間水解接續運送 (24h 持續供能)**：夜間無光合作用時，葉綠體暫存澱粉水解為【蔗糖】，沿韌皮部接續運送至塊根、根系、花朵、果實或頂芽，確保庫器官 24 小時晝夜獲得穩定能量。

2. **生理階段單步演示 (Step-by-Step Demonstration)**
   - 提供「**單步演示 (下一步)**」按鈕，可一步一步自主節奏觀察各生理階段：
     - **步驟 1/8**：晨光照耀，保衛細胞吸水膨脹，氣孔完全張開
     - **步驟 2/8**：大氣中 CO₂ 經由張開的氣孔擴散進入葉片氣室
     - **步驟 3/8**：根部吸收水分 (H₂O)，經木質部導管逆重力向上輸送至葉脈
     - **步驟 4/8**：葉綠體光反應吸收光能裂解水，釋出 O₂ 經氣孔排出，生成水產物
     - **步驟 5/8**：碳反應固定 CO₂ 合成醣類，即時轉化為蔗糖經韌皮部裝載運往庫器官 (日間即時供應)
     - **步驟 6/8**：日間光合速率大於即時運輸負荷，多餘碳聚合為【暫時性澱粉】「蓄洪」暫存於葉綠體 (避免高滲透壓)
     - **步驟 7/8**：夜幕降臨失去光照，保衛細胞失水萎縮，氣孔完全閉合 (光反應停止)
     - **步驟 8/8**：夜間葉綠體澱粉水解為蔗糖，韌皮部接續運送 (確保 24 小時晝夜穩定供能)
   - 點擊「開始自動循環」可隨時切換回全自動循環演示。

3. **雙模式顯微特寫視窗 (Microscopic Inset View)**
   - **視角一：氣孔保衛細胞機制**（移植自 stomata.html）：
     - 雙貝茲曲線向量細胞壁解剖模型（內壁厚不易伸長、外壁薄向外延展）。
     - 動態呈現 K⁺ 鉀離子與水分子滲透進出造成的膨壓變化與氣孔開閉。
   - **視角二：葉綠體與澱粉合成機制**：
     - 剖析雙層膜、類囊體基粒堆（光反應釋放 O₂ 與 ATP）與基質（碳反應固定 CO₂）。
     - 展示葡萄糖分子聚合成具同心輪紋的暫存澱粉粒合成中心。
   - 支援側邊欄按鈕與畫布微觀視窗標籤頁直接點擊切換。

4. **蒸散作用專題模式 (Transpiration Focus Mode)**
   - 提供「**蒸散作用展示**」獨立按鈕，聚焦水分子由根部吸收、沿木質部導管因蒸散拉力逆重力上升。
   - 氣孔全開時約 99% 水分自氣孔蒸散逸散為水蒸氣，約 1% 分流進入葉肉細胞供維持膨壓與光反應利用。

5. **頂部動態化學方程式看板**
   - 完整展示：`6 CO₂ + 12 H₂O ➔ 光能 ➔ C₆H₁₂O₆ (葡萄糖) + 6 O₂ ↑ + 6 H₂O↑ ➔ 縮合聚合 ➔ (C₆H₁₀O₅)ₙ (暫時性澱粉)`
   - 隨反應步驟即時動態高亮對應反應物與產物。

6. **養分庫器官分配與根部再動員**
   - 支援晝夜持續將蔗糖沿韌皮部運送至：
     - **地下塊根**：縮合轉化為儲藏澱粉。
     - **根系生長**：提供根尖分生組織細胞分裂、伸長生長與合成細胞壁之能量。
     - **花朵**：轉化為花蜜與開花代謝能量。
     - **果實**：積累果糖與果實膨大。
     - **頂芽**：合成細胞壁纖維素，促進節間伸長與新生嫩葉展開。
   - 支援春季萌芽時根部澱粉再水解為蔗糖，沿韌皮部向上再動員輸送至花朵、果實或頂芽。

## 啟動與使用方式

本專案為純前端原生架構（HTML5 + Vanilla CSS + JavaScript Canvas & Web Audio），無需安裝大型相依套件：

### 方式一：直接以瀏覽器開啟
直接在檔案總管中雙擊打開 `index.html` 即可完整運行。

### 方式二：透過本地 HTTP 伺服器開啟
在終端機中執行：
```bash
# Python
python -m http.server 8080

# 或 Node.js
npx serve -l 8080
```
接著在瀏覽器造訪：`http://localhost:8080/`

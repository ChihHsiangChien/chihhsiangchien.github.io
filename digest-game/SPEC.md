# 《人體消化大冒險》遊戲規格書 (Game Spec) 與科學正確性審查

---

## 第一部分：遊戲規格書 (Game Specification)

### 1. 核心概述
- **目標平台**：純前端單一網頁 (`index.html` + 原生 JavaScript + 原生 CSS)，無須 Node.js、無外部複雜建置流程，雙擊即可在瀏覽器開啟。
- **類型**：橫向滾動 / 益智反應科普遊戲。
- **主視角**：橫向橫截面消化道，食物顆粒從畫面左側（口腔）生成，藉由腸胃蠕動朝右側（大腸/肛門）滑動。
- **核心循環**：觀察飄來的養分顆粒 $\rightarrow$ 判斷當前所在器官 $\rightarrow$ 點擊下方對應消化腺噴射消化液 $\rightarrow$ 透過兩階段分解化為小分子 $\rightarrow$ 小腸吸收得分。

---

### 2. 消化道分區與按鈕版面配置

畫面橫向分為 5 大主要區段：

```
+-----------------------------------------------------------------------------------------+
| [HUD: 生命值(HP) | 分數 | 模式切換 | 關卡進度 | 當前食物訊息]                                   |
+-----------------------------------------------------------------------------------------+
|                                橫向消化道管腔 (食物流動區)                                 |
|                                                                                         |
|  [口腔]  ──>  [食道]  ──>  [    胃    ]  ──>  [小腸前段]  ──>  [小腸中後段]  ──>  [大腸]    |
| (澱粉第一段)  (緩衝區)    (蛋白質第一段)         (脂質乳化)        (最終水解吸收)      (未消化扣血)|
+-----------------------------------------------------------------------------------------+
|                                     控制按鈕區 (消化腺)                                   |
|                                                                                         |
|  [唾腺]                    [胃腺]             [肝臟]          [胰臟]    [腸腺]            |
| (唾液澱粉酶)             (胃蛋白酶+鹽酸)       (膽汁-無酵素)   (三合一全能) (雙醣/肽酶)       |
+-----------------------------------------------------------------------------------------+
```

1. **口腔 (Oral Cavity)**：
   - 下方按鈕：`[唾腺]` (Salivary Gland)
   - 噴射範圍：覆蓋口腔區間（水藍色酵素氣泡霧，持續 1.0 秒）。
   - 冷卻時間：1.5 秒。
2. **食道 (Esophagus)**：
   - 下方無按鈕：純蠕動輸送通道，作為玩家觀察與調整節奏的緩衝區。
3. **胃 (Stomach)**：
   - 下方按鈕：`[胃腺]` (Gastric Gland)
   - 噴射範圍：覆蓋胃囊袋內部（淡黃綠色強酸胃液霧，持續 1.0 秒）。
   - 冷卻時間：1.8 秒。
4. **小腸 (Small Intestine)**：
   - **小腸前段（十二指腸區）**：
     - 下方按鈕：`[肝臟/膽囊]` (Liver / Gallbladder)
     - 噴射範圍：注入小腸前段（黃綠色膽汁霧，持續 1.0 秒）。
     - 冷卻時間：1.5 秒。
   - **小腸中後段（空腸與迴腸區）**：
     - 下方按鈕：`[胰臟]` (Pancreas) 與 `[腸腺]` (Intestinal Gland)
     - 胰臟噴射：覆蓋小腸中段（金黃色強效酵素霧，持續 1.0 秒，CD 2.2 秒）。
     - 腸腺噴射：覆蓋小腸中後段（珠白色微光霧，持續 1.0 秒，CD 1.5 秒）。
   - **絨毛吸收區（小腸末端）**：
     - 所有已成功分解的「小分子」，經過此處時會發出微光並向上浮動被吸收，轉化為分數。
5. **大腸 (Large Intestine)**：
   - 無按鈕。
   - 進入此區的物體結算：
     - 若為大分子：重度消化不良，扣除 20 HP。
     - 若為中分子：輕度消化不良，扣除 10 HP。
     - 若為小分子：小腸漏吸（極少發生，不扣血但無分數）。
     - 若為不可消化的膳食纖維：化為正常糞便排出，無懲罰。

### 3. 分子狀態轉移規則（兩階段水解）

| 養分 | 階段 0：大分子 | 第一階段水解/作用 | 階段 1：中分子 | 第二階段水解 | 階段 2：小分子（吸收態） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **澱粉 🥖** | 巨大環狀糖鏈 (紫/褐色) | 口腔 `[唾腺]` (唾液澱粉酶) | **麥芽糖** (雙球體，橙色) | 小腸 `[腸腺]` (麥芽糖酶) 或 `[胰臟]` (胰澱粉酶) | **葡萄糖 ✨** (發光黃色小顆粒) |
| **蛋白質 🥩** | 摺疊多面團塊 (紅色) | 胃 `[胃腺]` (胃蛋白酶) | **多肽鏈** (串珠狀，粉紅色) | 小腸 `[胰臟]` (胰蛋白酶) 或 `[腸腺]` (肽酶) | **胺基酸 ✨** (發光青綠菱形) |
| **脂質 🧈** | 大油滴 (亮黃色球體) | 小腸前段 `[肝臟]` (膽汁物理乳化) | **乳化小油滴** (多個分散小黃球) | 小腸 `[胰臟]` (胰脂肪酶) | **脂肪酸 + 甘油 ✨** (金黃星芒粒子) |

*容錯機制（真實生理反映）*：
- 若玩家在口腔忘記噴唾液，澱粉進入小腸後，小腸中段的 `[胰臟]`（含胰澱粉酶）仍可先將其切成麥芽糖，再由 `[腸腺]` 切成葡萄糖（但需在小腸有限的時間內連續處理，難度增加）。

### 4. 關卡與模式設計

1. **初階模式（探索與教學）**：
   - 畫面一次**只出現 1 個養分顆粒**。
   - 飄動速度較慢（約 10~12 秒走完全程）。
   - 當顆粒飄到對應可消化的器官時，對應按鈕會有「微光提示」，引導玩家正確操作。
2. **中階模式（全速消化挑戰）**：
   - 連續出現**多個養分顆粒**（混合澱粉、蛋白質、脂質、纖維素）。
   - 移除引導光效，完全考驗玩家的**酵素專一性記憶**與**CD 管理**。
   - 顆粒移動速度加快（約 7~8 秒走完全程）。

## 第二部分：生物科學嚴謹度與潛在誤導深入審查

作為教育/科普向遊戲，我們必須預先排除中學生物教學中常見的迷思概念（Misconceptions）。以下列出審查要點與遊戲化解決方案：

### ⚠️ 潛在誤導 1：膽汁是「消化酵素」嗎？
- **真實生物學**：
  膽汁由肝臟製造、膽囊儲存，**不含任何消化酵素**！它對脂質的「乳化作用（Emulsification）」是**物理變化**（將大油滴物理打碎成小油滴，增大接觸表面積），而不是化學分解。真正的化學分解是靠胰液中的「脂肪酶」。
- **學生常見錯誤**：
  很多學生考試常誤填「膽汁能將脂質分解成脂肪酸與甘油」。
- **遊戲中防誤導設計**：
  1. 按鈕上明確標註：`肝臟（膽汁）- 物理乳化`。
  2. 動畫特效區隔：
     - 唾液、胃液、胰液分解時，使用「切斷/分解粒子迸裂」動畫。
     - 膽汁命中時，使用「大油滴晃動、分裂成多顆小油滴」的流體分散動畫。
  3. 狀態標籤文字提示：命中後飄出字樣 `物理乳化！表面積增加！` 而非 `分解！`。

---

### ⚠️ 潛在誤導 2：唾液澱粉酶到了「胃」還能工作嗎？
- **真實生物學**：
  唾液澱粉酶適合在中性偏微鹼（pH ≈ 6.5~7）環境作用。胃液含有強酸性鹽酸（pH ≈ 1.5~2），澱粉酶進入胃中會因強酸而**變性失去活性**。因此胃中完全不進行澱粉消化。
- **遊戲中防誤導設計**：
  - 如果玩家嘗試在「胃」噴胃液去打澱粉，或者澱粉在胃中停留時，完全不會有分解效果。
  - 若在胃噴胃液但擊中澱粉，跳出微小的灰色提示 `受質不符！胃酸不分解澱粉`，強化酵素的**專一性**與**最適 pH 值**觀念。

---

### ⚠️ 潛在誤導 3：胰臟的位置與胰液的注入點
- **真實生物學**：
  胰臟位於胃的後下方，胰管實際上是和膽總管一同（或分開）匯入**十二指腸（小腸最前端）**，而不是小腸中段。
- **遊戲性與科學性的權衡（Trade-off）**：
  - 若把肝臟和胰臟的按鈕都擠在小腸最前端，玩家在小腸前段必須一秒內連按兩下，手指容易打結，失去遊戲節奏感。
- **最科學又符合玩法的視覺呈現**：
  - 畫面上繪製出**導管（胰管與膽管）**，兩條導管皆源自器官並接至小腸前端！
  - 遊戲邏輯上：膽汁在十二指腸先乳化，隨腸道蠕動混合，食物漂至中段時正好由胰液的脂肪酶接力水解。
  - 在器官圖示旁加上小說明：`胰液經胰管注入十二指腸`，兼顧解剖結構正確性與操作遊戲性。

---

### ⚠️ 潛在誤導 4：大腸有消化吸收功能嗎？人體能消化纖維素嗎？
- **真實生物學**：
  1. 大腸**不分泌消化酵素**，主要功能是吸收水分與無機鹽。
  2. 人體缺乏「纖維素酶」，無法水解 β-1,4-糖苷鍵，因此膳食纖維（纖維素）會原樣進入大腸。
  3. 大腸內擁有龐大的**腸道共生菌群（微菌叢）**，會發酵利用膳食纖維與未消化的殘餘養分，並產生有益健康的短鏈脂肪酸（SCFA）與維生素。
- **遊戲中防誤導設計**：
  - 大腸下方**不設置任何消化腺按鈕**，標註為「腸道共生菌群」。
  - 增加**纖維素（膳食纖維）**分子，人體所有消化腺酵素對其皆無效，並彈出科學提示。
  - 未被小腸吸收的養分與纖維素進入大腸後，隨機被腸道菌發酵代謝消失，餵養益生菌獲得加分與健康回復，生動展現微生態生理機制。

---

### ⚠️ 潛在誤導 5：酵素專一性（Key and Lock）
- **真實生物學**：
  一種酵素通常只能催化一種受質（如唾液澱粉酶不能分解蛋白質，胃蛋白酶不能分解脂質）。
- **遊戲中防誤導設計**：
  - 若玩家隨意亂按（例如用胃腺打脂質、用唾腺打蛋白質），消化液會直接「穿透」或「彈開」，並顯示 `無作用 (專一性不符)`。
  - 不扣玩家分數，但會浪費該按鈕的 CD 時間，自然引導玩家學會辨識養分種類與對應酵素。

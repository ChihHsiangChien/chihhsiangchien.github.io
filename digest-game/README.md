## 📖 遊戲簡介

《人體消化大冒險》是專為生物科普、中學生物教學與自主學習打造的橫向滾動益智反應遊戲。玩家將扮演「消化道指揮官」，面對源源不絕進入人體的各類營養素（澱粉、蛋白質、脂質與膳食纖維），在正確的時機指揮對應器官分泌消化液，將巨大分子逐級水解為人體小腸能吸收的小分子！

## 🧬 生物科學核心機制

遊戲嚴格遵循人體解剖生理學與酵素化學原理，並特別針對中學生常見的「生物迷思概念」進行視覺與機制強化：

### 1. 兩階段水解與吸收機制

| 養分種類 | 階段 0：大分子 | 第一階段消化 | 階段 1：中分子 | 第二階段消化 | 階段 2：小分子（小腸絨毛吸收態） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **🥖 澱粉** | 巨大環狀多醣鏈 | **口腔 唾腺**<br>(唾液澱粉酶) | **麥芽糖**<br>(雙醣球體) | **小腸 腸腺/胰臟**<br>(麥芽糖酶/胰澱粉酶) | **葡萄糖 ✨**<br>(微光單醣) |
| **🥩 蛋白質** | 緊密摺疊多面團塊 | **胃 胃腺**<br>(胃蛋白酶 + 鹽酸) | **多肽鏈**<br>(串珠狀鏈) | **小腸 胰臟/腸腺**<br>(胰蛋白酶/肽酶) | **胺基酸 ✨**<br>(青綠菱形分子) |
| **🧈 脂質** | 巨大油滴團塊 | **小腸前段 肝臟**<br>(膽汁**物理乳化**) | **乳化微油滴**<br>(高表面積分散小球) | **小腸 胰臟**<br>(胰脂肪酶) | **脂肪酸 + 甘油 ✨**<br>(金黃微粒) |
| **🥗 纖維素** | 纖維多醣結構 | ❌ 人體無對應酵素 | ❌ 無法被人體水解 | ❌ 無法被小腸吸收 | 進入大腸由**共生菌群發酵**產生短鏈脂肪酸 (SCFA) |

### 2. 科學正確性與防迷思設計 (Scientific Rigor)

1. **⚠️ 膽汁不是消化酵素**：
   - 膽汁由肝臟分泌、膽囊儲存，**不含任何酵素**。
   - 遊戲中特別區隔特效：膽汁命中時呈現「大油滴晃動、分裂成多顆微小油滴」的**物理乳化**動畫，並標註 `物理乳化！表面積增加！`。
2. **⚠️ 酵素專一性（Key and Lock）**：
   - 酵素具高度專一性（如胃蛋白酶無法分解澱粉或脂質）。
   - 若對錯誤受質噴射消化液，消化液將無效穿透或彈開，並顯示 `無作用 (專一性不符)`，消耗冷卻時間。
3. **⚠️ 消化環境最適 pH 值**：
   - 唾液澱粉酶進入強酸性胃腔（pH 1.5~2）即變性失去活性，胃中不進行澱粉消化。
   - 未在口腔分解的澱粉，可在小腸由胰液中的胰澱粉酶接力分解。
4. **⚠️ 解剖導管注入呈現**：
   - 畫面忠實呈現肝臟膽管與胰臟胰管，兩者皆匯入小腸前端（十二指腸）。
5. **⚠️ 大腸與微菌叢（Gut Microbiome）**：
   - 大腸不分泌消化酵素。
   - 纖維素與未消化完全的養分進入大腸後，由共生菌群分解代謝，生成短鏈脂肪酸（SCFA），回復腸胃健康！

## 🕹️ 遊戲操作與關卡模式

### 操作方式
- **滑鼠 / 觸控點擊**：直接點擊下方的消化腺按鈕：
  - `[唾腺]` (口腔)：分泌唾液澱粉酶
  - `[胃腺]` (胃)：分泌胃蛋白酶與鹽酸
  - `[肝臟 / 膽囊]` (小腸前段)：分泌膽汁進行物理乳化
  - `[胰臟]` (小腸中段)：分泌胰澱粉酶、胰蛋白酶、胰脂肪酶
  - `[腸腺]` (小腸中後段)：分泌麥芽糖酶、肽酶
- **鍵盤快捷鍵**：支援數字鍵 `1` ~ `5` 快速釋放消化液！

### 關卡難度
- **🌱 初階模式（單分子教學引導）**：
  - 一次僅出現一顆養分分子，移動速度適中。
  - 當分子漂移至可消化的器官時，對應按鈕會有光效引導，適合初學者與課堂教學。
- **🔥 中階模式（大餐多工挑戰）**：
  - 模擬飽餐一頓的情境，多種養分顆粒密集連續通過。
  - 移除引導微光，考驗玩家對酵素專一性、器官分段與冷卻時間（CD）的管理技巧！

## 🛠️ 技術棧 (Technology Stack)

  - 自訂暗色系玻璃擬態（Glassmorphism）與生物螢光漸層。

  - 流暢的 CSS 微動畫與顆粒分解回饋。
- **部署平台**：GitHub Pages 靜態託管。

# 🌿 植物葉片橫切面 3D 微觀解剖模型 (Leaf Anatomy 3D Explorer)

基於 HTML5、JavaScript 與 Three.js 開發的互動式植物生物學 3D 教學展示系統。真實還原葉片橫切面的微觀立體構造與生理機制。

---

## 🔬 解剖結構與生物學特色

1. **角質層 (Cuticle)**：
   - 區分**上角質層**（較厚、高光感蠟質保護）與**下角質層**（較薄，留有氣孔開口）。
   - 防止水分蒸發並抵禦病原體。

2. **表皮細胞 (Epidermal Cells)**：
   - **上表皮**與**下表皮**：單層緊密排列的透明磚狀細胞，具大型中央液泡，**無葉綠體**（利於陽光直射穿透）。

3. **葉肉細胞 (Mesophyll Cells)**：
   - **柵狀組織 (Palisade Mesophyll)**：垂直直立密排長柱狀細胞，**富含大量葉綠體**（主要光合作用場域）。
   - **海綿組織 (Spongy Mesophyll)**：疏鬆不規則細胞，具廣大細胞間隙（氣室）與氣孔下腔，亦含有葉綠體，利於氣體交換。

4. **保衛細胞與氣孔 (Guard Cells & Stomata)**：
   - 位於**下表皮**，成對腎形排列。
   - **特化含有葉綠體**，且具備「內壁厚、外壁薄」的構造特性。
   - 支援 **0%~100% 氣孔開合連續滑桿控制**，真實模擬保衛細胞吸水膨脹外彎與失水緊閉過程。

5. **葉綠體 (Chloroplasts)**：
   - 在所有綠色細胞（柵狀組織、海綿組織、保衛細胞）內部清晰呈現雙凸透鏡狀立體顆粒。
   - 支援自體螢光發光與單獨高亮/透視。

6. **維管束 (Vascular Bundle)**：
   - **木質部 (Xylem)**：位於近上表皮側（上方），由厚壁中空導管與管胞組成，輸送水分與無機鹽。
   - **韌皮部 (Phloem)**：位於近下表皮側（下方），由細密篩管分子與伴細胞組成，輸送光合產物（有機養分）。
   - **束鞘 (Bundle Sheath)**：緊密環繞維管束外圍之保護鞘細胞圈。

## 🎮 互動功能說明

- **氣孔開合調控 (Stoma Control)**：
  - 0% 完全關閉、50% 舒張、100% 充分張開。
  - 連動保衛細胞外彎變形與氣體/水分分子擴散粒子流動。
- **組織構造高亮與隱藏 (Highlight & Hide/Show)**：
  - 左側面板提供所有組織層次清單，點擊「眼睛圖標」切換顯示/隱藏，點擊「準心圖標」聚焦高亮。
- **爆炸分解圖 (Exploded View)**：
  - 可垂直拉開各層次間距，直觀檢視被包覆在內部的維管束、海綿氣室及葉綠體。
- **細胞半透視 (X-Ray Mode)**：
  - 將細胞壁半透明化，透視內部懸浮之葉綠體群。
- **點擊即顯解剖卡片 (Click & Inspect)**：
  - 鼠標點擊模型中任一細胞，右側面板立即顯示其形態特徵、生理功能及生物學重點考點筆記。
- **預設導覽鏡頭 (Camera Presets)**：
  - 全景橫切、氣孔特寫、柵狀葉肉、維管束特寫一鍵切換。

## 🚀 如何運行

您可透過任何現代網頁瀏覽器直接開啟：

### 方式 1：直接雙擊開啟
直接使用 Chrome、Edge、Firefox 或 Safari 開啟本專案目錄中的 [index.html](file:///c:/Users/User/Documents/GitHub/leaf/index.html)。

### 方式 2：使用本機伺服器（推薦）
在終端機中於本專案目錄執行：
```bash
python -m http.server 8088
```
並在瀏覽器造訪：`http://localhost:8088`
